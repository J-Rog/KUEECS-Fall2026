    Write a program to simulate how the shell interprets the command:

    du -ak $1 | sort -nr | head -n $2 | cut -f2-

    This command will search through the directory given by the first argument for information pertaining to the size of files and directories and return the N largest files (where N is the second argument). You can use the lab's Makefile to run a bash script with this command:

    make disk_usage

    You can use the disk_usage.c file in the lab's archive as starter code for your program. When you have finished the program, use the build target in the lab's Makefile to compile it. The output of the correct program will match with the output of the finder.sh script which is also present in the lab's archive. You can use the

    make test

    target in the lab's Makefile to check it against the expected output.
