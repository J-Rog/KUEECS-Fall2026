    Lab 1 is a two part assignment to prepare you for the rest of this course. The first part of the assignment will be completing some C leet code problems involving linked lists. For this assignment follow the instructions in the comments of the LinkedList.h and ListQuestions.h. Then once you have completed those you can test your code using ./runtests.

    The second portion of this assignment is the bugs program. This program contains a number of bugs some of which are solved for you one the slides, the rest you will have to do yourself. Your bug.c program should contain corrections for the bugs we talked about in class as well as the ones you solve on your own. This assignment is to get you familiar with C debugging tools since AI is not permitted for this course.

  • 35% (bugs.c) - Correct output from bugs.c

  • 15% (Demo) - A quick demo of your submission will be taken on the following week during the lab hours (Questions will be asked)
