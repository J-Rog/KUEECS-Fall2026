    Lab 2 requires you to complete the signals.c file so that when the user types ctrl-c the program doesn't terminate but rather increments the ctrl-c counter.When the counter hits 5 the user should be given an option to end the program. When the user types ctrl-z the program should display how many times ctrl-c has been typed. The program should also terminate in the option to end the program if the user doesn't respond in 5 seconds. To do this write a signal handler for the SIGALRM signal.
