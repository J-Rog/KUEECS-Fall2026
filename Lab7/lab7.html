Lab 7: Priority Queues

This lab introduces priority queues implemented using a sorted linked list in C. Unlike a standard first-in, first-out queue, a priority queue arranges elements according to their priority. You will work with the provided libpriqueue library to implement your own priority queue.

Topics discussed in this lab include

  • Queue Theory
  • Priority Queues
  • Continuing our usage of C pointers
  1. Lab Slides
  2. Lab Files

Work with the libpriqueue implementation in libpriqueue.c and the interface declared in libpriqueue.h to implement a priority queue.

The library provides the following queue operations. Make sure you understand their behavior and that your implementation satisfies each contract:

  • priqueue_init — initialize a queue with a comparer function.
  • priqueue_offer — insert an element in priority order and return its index.
  • priqueue_peek — return the front element without removing it.
  • priqueue_poll — remove and return the front element.
  • priqueue_at — retrieve the element at a specified index.
  • priqueue_remove — remove all nodes whose item pointer matches the supplied pointer.
  • priqueue_remove_at — remove and return the element at an index.
  • priqueue_size — return the number of elements.
  • priqueue_destroy — free the nodes associated with the queue.

Compile the priority queue using the supplied Makefile:
